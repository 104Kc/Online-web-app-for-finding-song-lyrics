# ค้นหาเพลงจากเนื้อเพลง (Lyrics Search App)

เว็บแอปค้นหาเพลงจากเนื้อเพลงที่จำได้ (แม้จะจำผิดบางคำ) โดยใช้แนวคิดเดียวกับตัวอย่าง
`wongnai-gensim` ของอาจารย์ (PyThaiNLP ตัดคำ + gensim Word2Vec) แต่เปลี่ยนจาก
"รีวิวร้านอาหาร" มาเป็น "เนื้อเพลง"

**หลักการ:** เทรน Word2Vec จากเนื้อเพลงทั้งหมดในคลัง แล้วเฉลี่ยเวกเตอร์ของทุกคำ
ในเพลงหนึ่งเพลงให้เหลือเวกเตอร์เดียว ("song vector") เวลาผู้ใช้พิมพ์เนื้อเพลงที่จำได้
เข้ามา ก็แปลงเป็นเวกเตอร์ด้วยวิธีเดียวกัน แล้ววัดความคล้าย (cosine similarity)
กับ song vector ของทุกเพลง เพลงที่คล้ายที่สุดคือคำตอบ

โครงสร้างไฟล์:

```
lyrics-search-app/
├── data/
│   └── lyrics_sample.csv     # ข้อมูลตัวอย่าง (เนื้อเพลงสมมติ ไม่ใช่เพลงจริง)
├── train_word2vec.py         # เทรนโมเดล + สร้าง song vectors
├── search.py                 # ฟังก์ชันค้นหาหลัก (cosine similarity)
├── app.py                    # เว็บแอป Flask
├── templates/
│   └── index.html            # หน้าเว็บค้นหา
└── requirements.txt
```

## ขั้นตอนการรันใน VS Code

1. **เปิดโฟลเดอร์นี้ใน VS Code**
   `File > Open Folder...` เลือกโฟลเดอร์ `lyrics-search-app`

2. **สร้าง virtual environment** (เปิด Terminal ใน VS Code: `` Ctrl+` ``)
   ```
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # Mac/Linux
   ```

3. **ติดตั้งไลบรารี**
   ```
   pip install -r requirements.txt
   ```

4. **เทรนโมเดล** (ทำครั้งเดียว หรือทุกครั้งที่เปลี่ยนข้อมูล)
   ```
   python train_word2vec.py
   ```
   จะได้ไฟล์ `output/lyrics_w2v.model`, `output/song_vectors.npy`, `output/songs.csv`

5. **ทดสอบค้นหาทาง command line** (ไม่ต้องเปิดเว็บก็ได้)
   ```
   python search.py "ฝนตกที่หน้าต่างบ้านฉัน"
   ```

6. **รันเว็บแอป**
   ```
   python app.py
   ```
   เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:5000`

## ⚠️ เรื่องสำคัญ: ข้อมูลเพลง

`data/lyrics_sample.csv` ที่แนบมาเป็น **เนื้อเพลงสมมติที่แต่งขึ้นเพื่อทดสอบระบบเท่านั้น**
ไม่ใช่เพลงจริง (เพื่อเลี่ยงปัญหาลิขสิทธิ์) ก่อนจะส่งงานจริงต้องเปลี่ยนเป็นชุดข้อมูล
เนื้อเพลงจริงของตัวเอง โดยทำไฟล์ CSV ให้มีคอลัมน์เหมือนกัน:

```
song_id,title,artist,lyrics
1,ชื่อเพลง,ชื่อศิลปิน,เนื้อเพลงทั้งเพลง (ข้อความยาวๆ ในเซลล์เดียว)
```

แหล่งเนื้อเพลงที่ควรพิจารณา (ต้องตรวจสอบสิทธิ์การใช้งานเองก่อนใช้จริง):
- เนื้อเพลงที่ตัวเองพิมพ์/รวบรวมไว้เอง
- ชุดข้อมูลเนื้อเพลงแบบเปิด (open dataset) ที่ระบุอนุญาตให้ใช้เพื่อการศึกษา
- API ของผู้ให้บริการเนื้อเพลงที่มีเงื่อนไขอนุญาตให้ใช้งานลักษณะนี้

จากนั้นรัน `python train_word2vec.py --data data/lyrics_จริง.csv` ใหม่

## ข้อจำกัดที่ควรรู้ (เผื่อใช้เขียนรายงานโปรเจกต์)

- **คำที่ไม่เคยปรากฏในคลังเทรนเลยจะหาไม่เจอ** — ถ้าผู้ใช้พิมพ์คำที่ไม่มีในเนื้อเพลง
  ชุดใดเลย โมเดลจะไม่มีเวกเตอร์ให้ (ยิ่งคลังเพลงเยอะและหลากหลาย ยิ่งครอบคลุม)
- **จำเนื้อเพลงผิดแบบสะกดผิดเล็กน้อย** มีโอกาสแมตช์ได้ถ้าคำที่สะกดผิดนั้น
  เคยปรากฏในคลังเทรนด้วย (คล้ายที่ตัวอย่าง wongnai-gensim สาธิตเรื่อง `อร่ย` ↔ `อร่อย`)
  แต่ถ้าสะกดผิดแบบที่ไม่เคยมีในคลังเลย จะไม่ถูกจับคู่ — จุดนี้ปรับปรุงต่อได้ด้วยการ
  เพิ่ม fuzzy string matching (เช่น `difflib`) เป็นตัวช่วยสำรอง
- **นี่คือการค้นหาจากข้อความที่พิมพ์** ไม่ใช่การฟังเสียงร้องแล้วรู้จำเพลง (audio
  recognition) ถ้าต้องการให้ผู้ใช้ "ร้องใส่ไมค์" จะต้องเพิ่มระบบแปลงเสียงเป็นข้อความ
  (speech-to-text ภาษาไทย) ก่อนแล้วค่อยส่งต่อให้ระบบนี้ค้นหา
